# Data Access Control

Data access control ensures that people, systems, and partners can use the data they need while respecting security, privacy, contractual, and ethical constraints.

## Core practices

- Classify data by sensitivity, regulation, confidentiality, and business criticality.
- Define access roles based on job function and legitimate business purpose.
- Require approvals for sensitive data, privileged access, or exceptional use.
- Apply masking, tokenization, row-level security, or aggregation where appropriate.
- Review access periodically and remove stale permissions.
- Log and monitor unusual or policy-violating access patterns.

## Minimum access standard

Each governed data asset should document classification, permitted roles, approval path, required controls, retention expectations, and review frequency.
