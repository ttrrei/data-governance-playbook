# Data Catalog

A data catalog is an inventory of data assets enriched with metadata that helps people discover, understand, evaluate, request, and reuse data.

## Important metadata

- Asset name, description, domain, and owner.
- Source system and refresh frequency.
- Classification and sensitivity labels.
- Business terms, critical data elements, and related metrics.
- Known quality rules, limitations, and usage guidance.
- Access instructions and approval workflow.
- Lineage links to upstream and downstream assets.

## Governance practices

- Start with high-value datasets before cataloging everything.
- Require minimum metadata for certified or trusted assets.
- Make owners responsible for metadata accuracy.
- Measure adoption through searches, views, access requests, and reuse.
- Retire stale entries or clearly mark them as deprecated.
