# What Is Data Governance?

Data governance is the system of decision rights, accountabilities, standards, controls, and operating routines that helps an organization use data responsibly and effectively.

## What it includes

- Clear ownership for data definitions, quality, access, and lifecycle decisions.
- Shared policies and standards for data creation, use, protection, retention, and disposal.
- Processes for resolving issues, approving changes, and escalating cross-domain conflicts.
- Metadata practices that make data discoverable, understandable, and traceable.
- Controls that support privacy, security, compliance, risk management, analytics, and AI.

## What it is not

Data governance is not only a tool, a committee, a documentation project, or a centralized control team. Tools and committees can help, but governance becomes real only when responsibilities, standards, and decisions are embedded into daily work.

## Core outcomes

A good governance program improves trust, reduces ambiguity, speeds up responsible data access, lowers operational and regulatory risk, and creates reusable data assets that teams can confidently use.
